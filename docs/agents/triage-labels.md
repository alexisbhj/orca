# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Ready for agent qualification |
| ready-for-human | ready-for-human | Human action needed |
| wontfix | wontfix | Request declined |

Use the mapped label whenever a skill names a canonical role.
A ready-for-agent label alone does not authorize starting work.

Additional labels copied from Kin-RTS:
bug, documentation, duplicate, enhancement, good first issue,
help wanted, invalid, question, route:implement, route:spec,
route:grill, interne, urgent, bloqué, epic.

Copy missing labels with their original names, colors and descriptions.
Exclude `chez-paul`. Keep existing Orca labels.
